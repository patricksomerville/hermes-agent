# Voice Memo / Actors-Style Sound Collage Model

This reference describes the editorial target for Patrick's high-density audio collage work.

## Target

The edit should feel like one composite mind building an essay out of many real voices. The listener should be able to follow an argument, not only enjoy a texture.

## Grammar

- Preserve whole thoughts when they carry the idea.
- Do not cut off sentences halfway through. Let ideas complete and overlap.
- Use overlap and slight offsets intentionally. The overlap should begin where the listener's attention is switching.
- Use shared words, repeated phrases, breath, laugh, or rhythm as rivets between clips.
- Let a later voice enter before the previous voice fully leaves when the thought wants pressure or momentum.
- Let beds, room tone, and repeated motifs become connective tissue.
- Avoid hard waveform cliffs; handles and gentle fades are mandatory.
- Let the incoming clip fade up and the outgoing clip fade down across the overlap window, so the transition feels like a handoff.

## Wrong Default

Do not default to chopped-up word salad, generic podcast cleanup, clipped half-sentences, or simple talk-over-music. The core task is editorial thinking through sound.

## Useful Artifact Shape

- Source probe for any incoming sound file before editing.
- Paper edit with clip text and source timestamps.
- Rendered MP3/WAV proof.
- Timeline JSON with labels, speakers, transcript text, rivet words, gain, fades, and overlap.
- Review HTML for listening and revision.
- Status JSON with project duration, source count, clip count, and long-project marker.
